# Dismissal: design decisions supplied during review on #662

The maintainer resolved several previously-open design choices and asked that the
document express them as decisions rather than leave them as questions. This is
new direction for a draft architectural design, not a defect that an earlier
review process should have caught. The primary job incorporated those decisions
and the subsequent maintainer review approved the revised head.

## Grounds

The design job's completion record says that the original document deliberately
left several choices open. The PR history contains the maintainer's review, the
bot's thread-resolution replies, and a later approval, but no gauntlet or code
panel record. That absence is not a process miss here: this was a designer-owned,
draft design artifact awaiting the maintainer's architectural choices, rather
than a merge-ready build that should have gone through the gauntlet. No seat,
gate, or standing instruction is shown to require a panel to invent or pre-empt
those choices. The comment is recorded by URL for any verbatim re-fetch; its
untrusted text is not copied here.
