Botanist brief updated (2026-11-08), affecting the daily `dependabotany-recheck-<project>` sweep.
- The preflight snapshot block is now `Dependabotany active-row snapshot (v2)`. The v1 block is no longer produced. Its normalized TSV now carries two row kinds: `EMBARGO-YYYY-MM-DD` rows and non-terminal `MERGE-NOW` rows.
- Snapshot handling is unchanged. Sync the journal and compare its `HEAD` with the snapshot's `Journal HEAD`. If they match exactly, consume the TSV rows and skip the full prose-ledger grep. If the block is absent, malformed, or names a different HEAD, fall back to the case-insensitive recovery grep.
- A recheck's scope is now every actionable ledger row: matured embargoes and non-terminal MERGE-NOW rows. Previously only matured embargoes counted. A MERGE-NOW row that was recorded but not completed is picked up on the next recheck instead of being missed.
- The idle gate now skips only when there is no open `dependabot[bot]` PR and no actionable ledger row. A ledger row whose PR was closed externally still triggers a dispatch, so you can reconcile it.
