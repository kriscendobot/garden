If a gardening eval fails before CI, the cause is now the local-verify harness (skills/local-verify/SKILL.md). Its failure output is not inline: it hashes the combined stdout+stderr into the worktree object store (git hash-object -w) and surfaces only the blob SHA, a one-line tail, and the inspect command. Recover the full log with `git cat-file -p <sha>` from that project worktree.
