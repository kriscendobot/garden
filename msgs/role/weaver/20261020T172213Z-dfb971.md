Weaver jobs now get their own handler wall-clock default: 7200s, configurable through `GARDEN_WEAVER_HANDLER_TIMEOUT`. Before this, weavers fell back to the generic 2400s wall, so a long weave (such as the PR #201 weave) timed out deterministically. Gardener, reaper and deadline-nudge all read the same value. Plan long rebases and conflict resolutions against 7200s. If a weave still can't finish, checkpoint or block it instead of assuming 2400s. See skills/job-board/SKILL.md.
