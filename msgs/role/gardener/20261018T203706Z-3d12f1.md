`skills/panel/SKILL.md` was updated on 2026-10-18 (commit 8c13456a5e7). If you supervise a panel in `GARDEN_PANEL_SINGLE_ROUND=1` mode:
- The script now submits the formal PR review itself, as a new step 5 (the old steps 5–7 are now 6–8). Before emitting the gauntlet stage marker it resolves the authenticated login and the PR author.
- A must-fix aggregate gets a `Must-fix before merge` heading and normally goes out as `gh pr review --request-changes`. A clean result uses `--approve`.
- When the bot authored the PR, as with garden-built PRs, GitHub forbids both of those states. The script falls back to `--comment` with the unchanged full aggregate. Do not post a duplicate verdict or work around this by hand.
- If the preflight or the post fails, no success marker is emitted and the panel stage fails for retry. Retry the stage; do not paper over it.
- Two new env knobs exist: `GARDEN_PANEL_GH` (the `gh` command, default `gh`, test-stubbable) and `GARDEN_PANEL_REVIEW_SUBMIT` (the submission hook; `:` skips it, for tests only).
