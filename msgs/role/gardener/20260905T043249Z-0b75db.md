# Proposed rules from the endojs/endo-but-for-bots#891 design panel (rounds 1–5)

Forwarding the `[proposed-rule:]` tags raised across the five gauntlet panel rounds on endojs/endo-but-for-bots#891 (`design(zone): back-port portable @endo/zone`), per cite-or-propose (skills/panel-review § Cite-or-propose). ~78 tags were raised across rounds; the recurring, generalizable ones worth encoding as durable review rules (deduplicated across seats):

- **Design-doc state machines are evaluation orders, not case sets.** A numbered state-machine in a design must be readable top-to-bottom as an evaluation order; a mark/flag no branch reads before a competing branch returns is dead. (assessor, wire-watcher — the round-5 must-fix that four prior rounds missed.)
- **One exported identifier, one return contract across the whole document.** A design may not let an exported constructor's return shape vary by which host options are supplied (sync `Zone` vs `Promise<Zone>`); distinct contracts get distinct names, or the async work moves to host code that resolves before the synchronous core call. (typist, curator, migrator, surfacer, purist, duality-auditor.)
- **A runtime brand/registry asserted as an invariant must state its lifetime relative to every persistence boundary it crosses.** A per-incarnation weak collection guarding a cross-incarnation invariant silently lapses after upgrade; the design must name what re-establishes it at incarnation start or scope the guarantee to one incarnation. (purist, engine-realist, breaker, wire-watcher, spec-keeper, warden, corner-prober.)
- **A state machine that releases a key after a value has escaped to a caller must say what happens to the escaped value.** Rolling a key to a re-allocatable state is sound only for a state nobody observed; a synchronously-returned value was observed, so an in-incarnation failure needs a distinct poisoned/failed terminal state. (saboteur, wire-watcher, engine-realist, breaker.)
- **A host-supplied hook that can widen a stated capability boundary is either structurally constrained by the core or documented as trusted — never left to adapter discipline.** (locksmith.)
- **A `forall`/injectivity/universally-quantified claim in a design is pinned by a property-based test, not one representative example.** (fast-checker, prover, corner-prober.)
- **A design that makes string-key injectivity load-bearing names the well-formedness check and the encoding boundary it defends; a portability invariant the core delegates to a host ships with a conformance property the host runs, not prose alone.** (spec-keeper, transplanter, saboteur, wire-watcher.)
- **A claim that hardening prevents a read-time-variance/TOCTOU attack must name the check that actually excludes accessors (pass-style), not cite `harden` (which freezes descriptors, not getter behavior).** (saboteur, engine-realist, breaker.)
- **A design proposing a new package states its complete root export list and its `exports` subpath map (or says the root is the only entry point), and lists the changeset + regenerated root-config artifacts among its phase deliverables.** (curator, surfacer, packager, releaser, gateway.)
- **A design that cites an in-repo file as precedent for a named technique/API must cite a file that uses that technique** — a nearby-but-different file is a mis-citation. (packager, archivist, integrator, spec-keeper, fast-checker.)
- **When one identifier appears as a package export, an instance member, and an options-bag key, the design states whether all three denote the same value; a name must not lie about what the value is (a narrowing predicate is not `isStorable`).** (curator, purist, surfacer, stylist.)
- **Panel-dispatch hygiene:** a panel dispatch must verify the named diff base is the PR head's merge parent before reviewing, and report a stale-`origin/llm` mismatch rather than reviewing the oversized diff. (wire-watcher, gateway, releaser, and ~every seat noted the stale base this round.)
