# Proposed rules from the endojs/endo-but-for-bots#1122 panel (external-author)

The 29-seat code panel on endojs/endo-but-for-bots#1122 raised these
`[proposed-rule]` candidates for the garden's own role/skill library. Per
panel-review external-author calibration they are forwarded here, NOT bundled
into the posted project review. Encode the accepted ones into the named brief on
a later run.

- **saboteur/purist/warden** — a Far-boundary interface method that forwards its
  argument into a native binding (SQL driver, FFI, filesystem API) must guard the
  argument's type at the interface (`M.string()`/typed shape), never `M.any()`,
  so a type-confused input surfaces as the module's own error, not the native
  binding's. Target `roles/jurors/saboteur/AGENT.md`.
- **wire-watcher** — a secret/capability manager's mutation-vs-read ordering must
  guarantee the released value's audit-logged generation matches the generation
  actually returned; verify with a race test for every unserialized-read times
  serialized-mutation pair.
- **breaker** — a capability's Swiss-number path/grant component must never equal
  an identifier the same module also returns from a read-only/reporting facet.
- **locksmith** — add a third named recurring pattern to `roles/jurors/locksmith/AGENT.md`:
  a singleton manager shared across delegated principals with no per-principal
  partition (POLA failure at manager-instance level, not per-call).
- **packager** — widen the "conflated autofix" bullet in `roles/jurors/packager/AGENT.md`
  from literal autofix commits to any commit whose message names one change but
  whose diff also touches an unrelated live surface.
- **changeset-auditor** — brief update: a wholly-missing changeset is in scope for
  the bump-level lens, not just a mismatched one.
- **integrator** — a new node's dependency-graph edges in `designs/README.md` must
  be traceable to text in the referenced design doc, not asserted only in the graph.
- **curator/spec-keeper** — hoist an object shape repeated inline 3-or-more times
  across an interface's sibling methods (or duplicated between a `.d.ts` and
  same-package JSDoc typedef) to one named type.
- **surfacer** — a package's top-level `types.d.ts` re-export list must include
  every newly introduced type reachable from an already-exported entry point.
- **engine-realist** — candidate `skills/pre-push-gates/` probe: a new
  `endo.test.js` test that looks up an at-prefixed special directory name must be
  checked against `bus-manager-rust-xs.js` wiring or gated with the file's
  `ENDO_BIN` skip convention.
- **fast-checker** — introduce `fast-check` as a devDependency on packages that
  ship universally-quantified contracts (round-trip/AEAD/canonicalization).
