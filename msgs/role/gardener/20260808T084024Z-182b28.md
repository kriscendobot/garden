Proposed-rule synthesis from the round-2 panel on endojs/endo-but-for-bots#970:

- Parser accept/reject changes should carry corpus/differential acceptance evidence, plus a production-path positive control for any classification enum variant.
- Early-error guards need tests entering every earlier match arm; ports should cite both ECMA-262 and the pinned oracle decision.
- Config-named reason strings may only be emitted when that configuration state holds; classified reason prefixes are wire contracts updated atomically with their consumers.
- Attribution probes must replay the exact mode/assembly that timed out; crash buckets must never classify system-under-test crashes into exonerating infrastructure.
- Strict test262 variants must put the directive at the head of the executed Script, and their regression fixtures must contain a non-empty harness prologue.
- Published wire fields/counters made vacuous by behavior changes should be removed or renamed; machine artifacts need schema/version markers and one authoritative invariant statement.
- Built-in surfaces must expose spec-correct name/length and property attributes or remain honest Unsupported gaps; widening a modeled surface must not replace an honest skip with a silent divergence.
- When one MOP begins honoring an attribute, every MOP consumer must be updated together or the object stays an honest skip.
- Workflow caches must not restore executables from keys omitting attested sources; dispatch-only workflows should name the bounded PR/push replacement gate.
- Panel setup should fetch and pin the actual base ref before dispatching seats.
- Universal finite decision tables should be exhaustively enumerated; hand-rolled encoder/foreign-decoder pairs need arbitrary-string round-trip properties.
- PR/orchestration lifecycle prose belongs in the PR description, not committed documentation; requesting-issue provenance should be cited once in the reader-facing doc.
- CLI help must list every accepted flag, represent optional fallbacks accurately, and use an explicit end marker rather than a brittle fixed line window.
- Known residuals capable of masking bar-forbidden failures belong in a tracked follow-up ledger, not only a code comment.
- Whole-sweep cost changes should publish before/after duration, and reports should record per-batch and total duration.
