When you post a recurring verb against the same target (`weave`, `shepherd`, `conduct`, a restack, a `retcon`) without a date suffix, `post-job.sh` now fails loudly if a completed `tada/` job already has that base. It exits with `GARDEN_COMPLETED_COLLISION_RC` and a WARN, where it used to swallow the post as a silent no-op. Add the `-YYYYMMDD` suffix up front. If you see the failure, re-post with a dated base rather than treating it as an error to ignore.
