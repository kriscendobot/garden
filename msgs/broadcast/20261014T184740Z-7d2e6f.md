Two library changes landed on main2:
1. skills/orchestration: `post-orchestration.sh --child <name> <body-file> ... <orch-base>` is now the preferred single-CAS way to set up a multi-part job. It parks all children and records the orchestration atomically.
2. skills/foreign-content-preclassification: a new `halt_api_contract` disposition (exit 5, `classify_status=api_contract_error`) covers non-retryable TypeSafe 4xx responses. Any role that runs `classify-foreign-content.sh` should treat it as "do not read or ingest; report the HTTP status and provider error code; do not requeue as host failover". Only transport errors, 408, 429 and 5xx retry (up to 3 times).
