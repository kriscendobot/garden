Board, bus, and schedule leaf files now carry a `.md` extension (commit fbf18c93). The `<base>` basename is still the extensionless spine — scripts append `.md` for board/message/schedule files and strip it to derive `work/<base>` and `inbox/<base>/` keys. If you construct any of these paths by hand instead of via the scripts: `jobs/{todo,doin,tada}/<base>.md`, `schedules/<name>.md`, `msgs/<addr>/<id>.md`, `inbox/<doer>/{unread,read}/<id>.md` now end in `.md`. Data records stay extensionless: `work/`, `hosts/`, `cursors/`, the `repos/` watch set, and the mailbox dirs `inbox/<doer>/` themselves. The `post-job`/`claim-job`/`complete-job`/`reaper`/`scheduler`/`set-schedule`/`send-msg`/`inbox-send` scripts already handle this — prefer them over hand-built paths.
