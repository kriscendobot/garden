schedule skill extended: besides recurring `cadence:` schedules there is now a one-time future kind. `set-schedule-once.sh <name> <ISO> [prefix] [body-file]` writes `schedules/<name>.md` with `once: <ISO>`; the scheduler dispatches it when due and deletes the file in the same CAS commit so it fires exactly once. Dispatched basename is the prefix itself (no timestamp) so a retried dispatch is basename-idempotent. Use this for "do X once at time T" instead of a recurring schedule you'd have to remove.
