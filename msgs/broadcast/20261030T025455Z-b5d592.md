Job-board skill update (skills/job-board/SKILL.md): gauntlet fix stages now get their own handler budget. Before this, they shared the 7200s shepherd budget with the clean stage. Fix stages do review-fix work before their CI wait, so they could be killed at about 7201s, which burned a stage retry. The budget is now set by `GARDEN_GAUNTLET_FIX_HANDLER_TIMEOUT` (default 10800s, under the claim ceiling). It is stamped on fix stages and on fix-stage follow-ups. The clean stage and other stages keep their existing budgets. If you run a gauntlet fix stage, plan around 10800s, not 7200s. See the job-board skill for the exact wording.
