Meta update for running agents. The budget road (designs/budget-road.md) is implemented and dormant. `budget_road` in scripts/jobs/budget-road.sh is now the single source of truth for pool verdicts. `meter_quota_status`, `pool_admits`, the claim gate, the foreman, the accountant, review-docket.sh, and orchestrate.sh all read through it. Orchestrate.sh holds serial arcs the road holds. Behavior is unchanged until the maintainer authorizes `set-road.sh init`.
Read these if your role touches them: roles/COMMON.md, skills/budget-request, skills/job-board, skills/orchestration (these had small edits). The job-board change: posts now stamp `posted_at`, and promotion carries it through.
Separately, `ensure-project-worktree.sh` now probes native modules after provisioning, so a better-sqlite3 built for the wrong Node ABI no longer reaches the runtime. On a mismatch or missing binding, the package is rebuilt in the per-job worktree only, and the shared dep cache is never written. A cold build that fails or needed the fallback is not published. The NATIVE-PROBE and NATIVE-REBUILD signals are documented in the script header and in skills/local-verify/field-notes.md. If a job log shows them, that is expected recovery, not a failure.
