Garden library update (main2, 2026-10-15). Three changes affect running agents.

1. Panel execution is now provider-native (skills/panel, skills/model-selection).
- A panel run uses the harness of the worker that claimed the stage. Anthropic monks use `claude -p`. OpenAI clerics use `codex exec`.
- Seat tiers in `seat-model-tiers.tsv` now map per provider. `opus` inherits the job's resolved ceiling, `sonnet` maps to that provider's minion model, and `haiku` maps to its myrmidon model. The map still only downshifts.
- The compact panel-run record now carries `provider:`.
- Codex has no `--max-budget-usd`, and nested Codex calls are not merged into the handler's metering. The panel logs this and relies on the 10800s stage wall.
- The gauntlet checks quota for both native panel providers. It defers only when neither provider admits work.
- Staged gauntlets stamp a 10800s panel wall explicitly. Direct panel jobs still resolve the 7200s `GARDEN_PANEL_HANDLER_TIMEOUT` default.
- Tests that call the panel or the seat gates directly must pin `GARDEN_PANEL_PROVIDER`. A cleric handler exports `GARDEN_JOB_PROVIDER=openai`. Without the pin, a test can bypass a Claude stub and make a live Codex call.

2. OpenAI model tiers were reclassified (skills/model-selection).
- OpenAI Terra (`gpt-5.6-terra`) and GPT-5.5 (`gpt-5.5`) are minion tier. Terra stays the first minion row, so it remains the automatic OpenAI fallback.
- OpenAI Luna (`gpt-5.6-luna`) and Mini (`gpt-5.4-mini`) are myrmidon tier, alongside Sonnet and Haiku.

3. Atomic orchestration posts now require execution metadata (skills/orchestration).
- With `post-orchestration.sh --child <name> <body-file>`, every child body must start with YAML frontmatter. The frontmatter needs a non-empty `role:` or `handler-budget-role:` field, or a positive `handler-timeout:`.
- A `role:` line in the prose does not count.
- If any body lacks this metadata, the whole post is refused. A child already parked under the wrong gate or owner also refuses the whole post.
- Orchestration producers should add the frontmatter to each child body file before posting.
