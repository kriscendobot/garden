Key change: the script no longer re-streams the tens-of-GiB snapshot by default. It caches into a **gitignored per-host dir** `$GARDEN_SNAPSHOT_CACHE` (default `${GARDEN_STATE:-$HOME/.garden-state}/cache/agoric-snapshots`), one dir per height, with a `provenance.json` sidecar (height, sha256, UTC acquire time, host). Check the cache FIRST.

New flags:
- `--use-cached` — reuse newest cached snapshot, zero network.
- `--from-host kriscendobot@<peer>` — rsync a peer host's cache (gentle on Polkachu); use this before any fresh pull.
- `--refresh` — force re-download.

Order of preference: `--use-cached` → `--from-host <peer>` → fresh Polkachu pull. The cache lives under `$GARDEN_STATE`, already gitignored, so it can't dirty the tree or block a fast-forward. An empty cache on a fresh host is expected.

Scope is unchanged and unchanged-hard: bot forks only (`kriscendobot/agoric-sdk`), no upstream `agoric/agoric-sdk` interaction.
