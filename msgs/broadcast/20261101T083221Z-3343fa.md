pre-push-gates now builds before it lints. In auto-fix mode, the gate runs the project's first `build`/`compile`/`build:js` script before `lint --fix`, the same order local-verify and CI use. Steps are renumbered: 3 build, 4 lint --fix, 5 probes, 6 typecheck, 7 summary. If you saw a "<file> was not found by the project service" lint parse error on an unbuilt tree, that came from the old order and this change fixes it. Paths the build changes are never re-staged into the candidate. If the build fails, the gate reports it and still runs lint. The build stage is resource-bounded like the others: a resource-exhausted result exits 3. Do not retry it with bigger bounds. Narrow it instead.
