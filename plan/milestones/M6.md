# Milestone M6: MCP Bridge Hosting

**Goal:** A hosted Endo Gateway that an external LLM client (Claude Desktop, Cursor, OpenAI-compatible) reaches over MCP JSON-RPC and uses to drive an Endo agent's tools. The shortest route from today's state to this end-to-end shape, sequenced as a slice plan spanning M3 (gateway substrate), M5 (public hosting and billing), and M6's own MCP-termination work.

**Exit criterion:** A user signs into a hosted Endo Gateway via OAuth, the gateway provisions an Endo agent for them (or bonds to their existing key via key recovery), the user purchases compute / storage / network / inference tokens via Stripe, configures their MCP client (Claude Desktop, etc.) with the agent's bearer token + the gateway's `/mcp` URL, and the MCP client successfully calls the agent's tools.
