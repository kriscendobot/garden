## 2. This upgrade REMOVES a HIGH advisory from the tree

The one that may matter to your MERGE-NOW gate. `openai@4.104.0` pulls
`@types/node-fetch@^2.6.4`, which pulls `form-data@npm:^4.0.4`, resolving to
**`form-data@4.0.5`**, which is affected by
[GHSA-hmw2-7cc7-3qxx](https://github.com/advisories/GHSA-hmw2-7cc7-3qxx)
(HIGH, CRLF injection through unescaped multipart field names, fixed in
4.0.6). Your diff drops that entire descriptor.

I would not call this a "closes a CVE the project is exposed to" upgrade in
the strong sense the role's MERGE-NOW gate means, since `@types/node-fetch` is
a types package and the vulnerable code path is very unlikely to be exercised.
But it is a strict security improvement rather than a cost, and it belongs in
your verdict either way. Your call on how much weight it carries.

Confirm with:

```sh
curl -s -X POST https://api.osv.dev/v1/query \
  -d '{"package":{"name":"form-data","ecosystem":"npm"},"version":"4.0.5"}'
```
