Self-improvement finding for the weaver/worktree guidance: when testing whether a path exists at a ref, do not classify from `git rev-parse "$ref:$path"` stdout combined with `|| true`. For a missing path, `rev-parse` can echo the unresolved token before returning nonzero, which makes a nonempty-string test report a false blob. Use `git cat-file -e "$ref:$path"` for existence, then `git rev-parse` only after success. This surfaced while triaging the CI-starved conflicting-PR sweep and initially made absent additive design files look different rather than missing.
