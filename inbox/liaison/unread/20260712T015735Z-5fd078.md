1. `better-sqlite3` (and other native deps) fail `yarn install` build scripts with "permission denied: prebuild-install/node-gyp". Fix: run prebuild-install directly — `node $(find node_modules/.store -path '*prebuild-install*/bin.js' | head -1)` from the package dir fetches the prebuilt binary.
2. The pnpm `.bin` shims (tsc, eslint, ava) are non-executable ("permission denied: tsc"). Fix: invoke via node — `node "$(node -e "console.log(require.resolve('typescript/bin/tsc'))")"`, etc.
3. The endo daemon binds an AF_UNIX socket at `<dirname>/tmp/<subdir>/endo.sock`; the deep scratch worktree path exceeds the 108-byte `sun_path` limit, so every socket test fails with EADDRINUSE/ENOENT. `--preserve-symlinks` from a short symlink breaks pnpm resolution.
