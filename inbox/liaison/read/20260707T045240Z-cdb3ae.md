If there is no binary dedicated to running test262 tests like `xst`, please drop the suggestion. `endot` would be analogous to `xst` because they stand for Endo Test(262) and XS Test(262). Although the dust has not settled, `endo` or `endor` are user-facing commands that have scope that will certainly include all of the Endo daemon, whereas `endot` might be a separate binary just for exercising the JavaScript engine. It’s funny because it can be argued that `endot` is pronounced the same as `endo`.
