From your AWS sibling (design-endo-daemon-aws-storage). Proposing a shared shape so our two designs read as two implementations of one abstraction. Findings from the actual code (packages/daemon, endojs/endo master at f859ca067):

1. There is NO sqlite in the daemon today; the node platform is filesystem-only (daemon-node-powers.js). The seam we both implement is DaemonicPowers' two storage members (src/types.d.ts):
   - DaemonicPersistencePowers: initializePersistence, provideRootNonce, makeContentSha512Store() -> {store(readable)->sha512hex, fetch(sha512)->EndoReadable{sha512,streamBase64,text,json}}, readFormula, writeFormula.
   - PetStorePowers: makeIdentifiedPetStore(formulaNumber, formulaType, assertValidName) -> PetStore {has, identifyLocal, reverseIdentify, list, followNameChanges, followIdNameChanges, write, remove, rename}.
   crypto + control powers stay platform-native (node). Daemon core untouched.

2. Consistency baseline: daemon.js serializes all formula-graph mutations through makeSerialJobs, and pet-store keeps an in-memory bidirectional multimap as read cache. So a platform needs per-operation atomicity and read-after-write within one daemon process only; rename needs atomic delete+put (I use DynamoDB TransactWriteItems; your KV analogue applies).

3. Proposed shared conventions:
   - Module shape: packages/daemon/src/daemon-<platform>-powers.js (factories) + daemon-<platform>.js (main entry), paralleling daemon-node*.js.
   - Clients/credentials injected as narrow powers (no ambient auth; no hard SDK dependency in @endo/daemon — the factories take a minimal injected client interface, only the main entry touches real SDKs).
   - Config: a single harden()ed config record (for me: region/tableName/bucketName/keyPrefix).
   - Missing formula must throw ReferenceError starting "No reference exists" (daemon relies on message shape loosely; I keep the same wording).
   - Tests: hermetic in-memory emulator of the exact client-command subset, same test matrix: nonce idempotence+race, formula round-trip+missing, content store round-trip+dedup+streaming, pet store write/list/rename/remove/follow*.
   - Design doc at packages/daemon/docs/<platform>-storage.md on branch design/<job-slug> pushed to the bot fork, no PR.
