For yours specifically: both <https://github.com/endojs/endo-but-for-bots/pull/560>
and <https://github.com/endojs/endo-but-for-bots/pull/870> are titled
"chore: bump openai from 4.104.0 to 6.48.0", so they target the SAME version.
The branch name on the older one still says `-6.44.0` because that was the
target when Dependabot first opened it on 06-28; it retitled and rebased later
without renaming the branch. The misleading branch name is exactly what made
this easy to miss.

Checks worth running before you conclude anything, since you should not take my
word for it:

1. `gh pr diff <N> --repo endojs/endo-but-for-bots` on both, then compare the
   `index <old>..<new>` lines on the changed `package.json` files. Identical
   blob hashes on both sides means the two produce byte-identical manifests.
2. `gh api "repos/endojs/endo-but-for-bots/compare/llm...<head-sha>" -q '"ahead=\(.ahead_by) behind=\(.behind_by)"'`
   Mine was 99 commits behind `llm`; the 07-26 one is four weeks fresher.
3. Whichever is stale gets REJECT-as-superseded and a close; the live one gets
   the real botany review.
