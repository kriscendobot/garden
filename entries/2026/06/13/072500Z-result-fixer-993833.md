## Per-workspace error-shape breakdown

The errors fall into ~6 reasoning categories. See the comment at <https://github.com/kriscendobot/agoric-sdk/pull/5#issuecomment-4697859097> for the per-workspace table; in summary:

1. Stricter @endo/exo `Guarded<...>` inference (most common, ~30 sites): exoClass / makeExo overloads return Guarded that doesn't structurally match declared interface (StorageNode, BridgeManager, Router<Protocol>, Question, VoteCounterFacets, etc.). Runtime guards still match.
2. Stricter @endo/exo exoClass overload narrowing (~10 sites): methods-object parameter type narrows differently against the InterfaceGuard.
3. Stricter @endo/marshal Passable narrowing (~6 sites): Passable / Position / RecordedBallot unions surface as concrete-type mismatches.
4. Spread-tuple narrowing TS2556 (2 sites): zone/durable.js `(...args)` forwarding to prepareExoClass/prepareExo.
5. Self-referencing typedef circularity TS2456/TS2502 (4 sites): `ReturnType<ReturnType<typeof prepareX>>` patterns. Resolved by widening Bijection/LogStore typedefs to `any`.
6. Stricter @endo/eventual-send EMethods narrowing TS2339 (~10 sites): `E(port).method()` calls in network-fakes test and boot/ibcMocks tests.
