## XS value-stack overflow: root-caused and fixed (the headline)

The ymax0 v320 70->71 upgrade overflowed the XS value stack on bundle import. The
arc closed across kriskowal/garden #9 and #17:

- **Diagnosis.** `investigate-ymax0-xs-overflow-symbolicated-stack-trace` produced
  the symbolicated frame, fingering the `hex` frame that overflowed at
  `stackCount=4096`. The mechanism: native `flatAux` defines each element into the
  heap result array but never pops the spent value-stack slot, so peak value-stack
  use is O(flattened output length), not O(depth).
- **Real-chain reproduction.** `kriskowal-garden-pr9-*` (7 jobs) landed the
  `agoric-chain-snapshot` skill and `fetch-polkachu-snapshot.sh` /
  `fetch-chain-snapshot.sh` (gitignored per-host cache, `provenance.json`
  sidecar), and `reproduce-ymax0-v320-real-chain-state-20260630` exercised a real
  mainnet swing-store against the repro harness.
- **Engine fix (shipped).** Issue #17's builder added one per-iteration `mxPop()`
  to `fxArray prototype flatAux` (`xs/sources/xsArray.c`), mirroring `forEach`'s
  O(1) pattern; GC-safe because each slot is popped only after its value is
  heap-rooted. **A/B build-verified** at XS 13.3.0 / `stackCount=4096`: stock ->
  exit 12 STACK_OVERFLOW, patched -> import completes. Opened as
  **kriscendobot/moddable#1** (base+head on the bot fork; no upstream
  interaction), with a `flat`/`flatMap` semantics suite passing identically.
- **Contract-side fix.** `shepherd-kriscendobot-agoric-sdk-pr7` and the
  `agoric-sdk-fork-rebase-pr-7` / `-regen-fetched-chain-info-master` pair advanced
  the complementary `hex.js` loop fix on **kriscendobot/agoric-sdk#7**. The rebase
  proved a no-op (already on master tip); its one red check is the master-level
  stale-codegen issue (`fetched-chain-info.js`), which the regen peer owns — the
  two coordinated over the bus, with a dead-letter-promoted rebase-refresh as the
  self-healing path once the regen merges.

Both fixes address the same overflow at different layers (the engine fix is the
*class*; the contract loop is the *instance*) and can land independently. Carrying
the engine fix upstream to agoric-labs/moddable is a separate credentialed
(boatman) step, flagged out of autonomous scope.
