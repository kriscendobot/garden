## Garden-meta

### Library and tooling changes

Four garden changes landed on `main2`. The exact-current-head approval guard was removed
with prejudice: `pr-maintainer-approval-gh.sh` now authorizes on a maintainer's effective
(latest) review state of approved with no outstanding changes-requested, so a rebase no
longer stales an approval, while dismissal and any changes-requested veto still refuse
(`../../../jobs/tada/garden-current-head-approval-guard-remove-5053510672.md`). A new
bare-numeric `gh pr` scope guard rejects a numeric selector that carries no repository or
pull-request URL when run outside a project worktree, closing the ambiguity that turned a
bare `#51` into a handler failure
(`../../../jobs/tada/improve-reject-ambiguous-bare-pr-lookup.md`). A typedef placement
convention was encoded into builder and fixer guidance, with the typist juror assigned
verification and a narrow deterministic probe kept over a broad scanner
(`../../../jobs/tada/garden-encode-typedef-review-convention.md`). The root-repo guard
gained a recurring low free-inode alarm with coalesced maintainer alerts and no unattended
deletion (`../../../jobs/tada/self-heal-fix-garden-comment-watcher-kriscendobot-ymax-stdio-mcp-host-inode-exhaustion.md`).
