scripts/jobs/claim-job.sh
`job_eligible_for_kind()`'s §1.3 backend-fit filter checks only tier/provider/model-pin compatibility, with a role-aware carve-out for exactly one case (mystic refuses `builder|designer`). It has no analogous carve-out preventing a `hermit` (or `cleric`/`fireworker`) worker from claiming a `role: gardener` job: a tier-only job (no `model:` pin) is "claimable by any provider that has a model at that tier," and `local/qwen3.6` is classified tier `minion` in model-tier-inventory.tsv, so a hermit passes the filter on any unpinned `tier: minion` gardener-role job.

Observed impact: `mtown-git-remote-followup-notice-recheck-20260818` (role: gardener, tier: minion, no model pin — the automatic-dispatch default from `automatic_route_body`) was claimed by `worker_kind: hermit` and died at a near-constant ~5s elapsed across 3+ requeue cycles on two hosts (endolin-garden-ece02cb4, endolin-garden2-5bcdff64) between 02:23Z–02:44Z on 2026-08-19 — the hermit's codex handler (`handlers/cleric-codex.sh`) and `role_default_model`'s hermit case (`common.sh`) were never built to run the full agentic `gardener` role. The gardener fleet's own elapsed-constancy detector correctly flagged this as a deterministic bug misclassified as transient (`023448Z-error-gardener-728b24.md`) and escalated to the maintainer inbox, but only after burning most of the doom-threshold requeue budget on two hosts. The same job basename ran fine under the anthropic `gardener` kind on 2026-08-15/16 (86s/237s, claude-opus-5), confirming the job itself is sound — the claim eligibility gap is the defect.

Fix: extend `job_eligible_for_kind()` (or a sibling predicate it calls) so a job whose `role:` requires the Claude-agent posture — `gardener` at minimum, and any other role never listed in a non-`gardener` kind's `role_default_model`/handler vocabulary — is claimable only by `KIND=gardener` (provider anthropic), the same way mystic is already fenced off from `builder|designer`. This stops hermit/cleric/fireworker/mystic workers from winning claim races they cannot honor, before they burn reap cycles and require the elapsed-constancy escalation path to notice.
