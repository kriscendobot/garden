# Has Moddable's XS 65535-locals-per-frame parser fix landed upstream yet?

Recurring check. Read-only against upstream until the fix appears; the run that
finds it is the terminal run and retires this schedule.

## Background (kriskowal, 2026-09-14)

XS has a hard limit of **65535 locals in a frame**. The parser was not checking it
and generated byte code that could crash in various ways; OSS-Fuzz found several
paths to it, Fuzzilli did not. The fix rejects such scripts at parse time and
"will be in our next release". Not upstream as of 2026-09-14
(`Moddable-OpenSource/moddable` master tip `b6e06ba70`, 2026-09-04).

Iron Horse's own port of this check is job
`ironhorse-port-xs-frame-locals-limit` (endojs/endo-but-for-bots, branch `llm`,
crate `rust/engine/ironhorse-compile`), built independently from the description
above rather than from the upstream patch.

## Each run

1. **Check upstream.** Look at `Moddable-OpenSource/moddable` master, and any
   release tag newer than 2026-09-04, for a parser-side check on frame local
   count. `Moddable-OpenSource/moddable` is an UPSTREAM third-party repo: read
   only. Do not comment, open issues or PRs, or otherwise interact with it.
2. **If not found:** report "not yet landed", naming the tip sha and date you
   checked, and stop. This schedule ticks again in a week.
3. **If found — the terminal run:**
   a. Read the fix and record its semantics: the exact limit, where it is
      enforced, what error it raises, and which declaration forms it counts.
   b. Compare against the Iron Horse port. Report any divergence in limit,
      enforcement point, error shape, or coverage, and post a follow-up job to
      reconcile Iron Horse if they differ.
   c. Verify the XS fix itself: build XS at that commit and confirm it rejects an
      over-limit script that pre-fix XS crashed or misbehaved on. Experimentation
      belongs on the `kriscendobot/moddable` fork or a local build, never upstream.
   d. **Retire this schedule**: delete
      `schedules/xs-frame-locals-limit-upstream-watch.md` from `journal2` and push
      (a normal CAS commit). Say in your report that you retired it, so the
      maintainer knows the watch has stopped.
