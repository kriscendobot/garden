`scripts/jobs/set-schedule.sh` writes a `preflight:` frontmatter line without checking that the referenced script resolves to an executable. The `xs2rust-endor-press.md` schedule points at `gardening/xs2rust-endor-press-preflight.sh`, which does not exist under `scripts/jobs/gardening/`. At dispatch time `scheduler.sh` (line 126) hits the missing-preflight branch and logs `WARN ... treating as work-present`, which silently defeats the deterministic no-work gate: the press job is posted every cadence regardless of whether there is any work, spending a gardener each tick. Harden `set-schedule.sh` to resolve a supplied preflight (relative to `scripts/jobs/`, mirroring the scheduler's `HERE`-relative resolution) and refuse — or at minimum loudly reject — a path that is not an executable file, so a dangling/typo'd preflight can never land and degrade the gate into always-dispatch. Either that, or the missing `scripts/jobs/gardening/xs2rust-endor-press-preflight.sh` gate must be authored so the schedule's gate actually functions.
