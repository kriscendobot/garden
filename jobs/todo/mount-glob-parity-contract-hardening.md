Harden the endo-but-for-bots mount-glob shared cross-language parity contract so the #654 Rust/XS parity runner cannot pass while diverging from the Node reference. Surfaced by the garden review panel on PR #653 (feat(daemon): mount glob). All items are additive to the shared fixture/case table under packages/daemon/test/; none change mount.js behavior.

1. UTF-16 astral sort-order case (highest value). Add a fixture entry pair whose UTF-16-code-unit order (JS Array.prototype.sort) differs from code-point/UTF-8 order — an astral name (>= U+10000, e.g. an emoji U+1F4xx) alongside a high-BMP name (e.g. U+E000-F8FF private-use or U+F900-FAFF). Pin a glob case over it so a Rust port sorting by natural str Ord fails the table. Note: adding fixture entries ripples through every existing `**`/`*` root-enumeration expectation in mount-glob-cases.json — regenerate them carefully.
2. Escape-symlink target in the shared manifest. The `escape -> ../escape-target` target, its dir, and secret.txt are created imperatively in test/_mount-fixture.js above the root, not declared in mount-fixture-manifest.json. A Rust runner reading only the manifest creates a broken link, so both requiresSymlink cases pass vacuously. Move the above-root setup into the manifest (e.g. an `outsideRoot` section).
3. Full deny set in a shared artifact. defaultDeniedSegments is 14 entries matched case-insensitively; only .ssh/.aws/.env are in the fixture + case table. Encode the full list and the case-fold rule in a shared artifact so a port cannot under-deny and still pass.
4. Contract constants as shared data. GLOB_MAX_RESULTS (10,000, post-sort truncation) and the symlink-cycle semantics (record-once) are JS-only tests; a port could pick a different cap/none and pass the table. Encode them in the shared contract.
5. Matcher literal test-gaps. Add case-table entries for `?` as a literal (the sharpest POSIX divergence), embedded `a**b` collapse, and `{`/`}` literals — all documented normatively but unexercised.

Also optional (Node-side polish, non-parity): tighten the "** matches zero or more directory levels" wording across the four doc surfaces to note trailing ** also matches file descendants; drop the two redundant mid-walk names.sort() calls in glob's walk (the final sort governs output order). Consider a caller-visible truncation signal for GLOB_MAX_RESULTS, or continue to defer to the streaming search variants.

Post as a fixer/assayer job against endojs/endo-but-for-bots when #654's parity direction is settled, so the shared fixture is revised once for both PRs.
