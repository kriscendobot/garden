A transient `gh` failure (rate-limit / network / auth blip) on `gh pr list` — or on the `rids="$(gh api … 2>/dev/null | jq | sort -u | tr …)"` command substitution at line ~99 — exits the pipeline non-zero with its error text swallowed, killing the whole source.
