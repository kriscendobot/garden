scripts/jobs/gardening/detect-catch-all-swallow.sh
Add a new deterministic (no-LLM) gardening detector, modeled exactly on `scripts/jobs/gardening/detect-banners.sh`, that closes the `catch-all-error-swallow` prevention-gap the prosecutor flagged on endojs/endo-but-for-bots #678 (and earlier #653). The panel's saboteur juror checks try-body *width* but not error-class *breadth*, so a bare `catch { return undefined }` / `catch {}` / `catch (e) { return undefined }` that swallows EVERY error class (no `instanceof`/`.code`/`.name` narrowing and no rethrow) slips past review; because such a swallowed error feeds a confinement decision, the miss is also security-relevant.

New script mirrors detect-banners.sh's contract:
- Scope to added diff lines only (against a base ref; no base → quiet "clean", exit 1) and to CODE files (js/ts/jsx/tsx/mjs/cjs).
- Subcommands `check <worktree> [base]` (exit 0 = a catch-all swallow was added, exit 1 = clean) and `lines <worktree> [base]` (print `<path>: <text>` for each offender, consumed by the fixer handler).
- FAVOR FALSE POSITIVES: flag any added `catch` block whose body neither narrows on error class/code nor rethrows/logs; the saboteur juror remains the backstop.
- Add a matching test under `scripts/jobs/test/detect-catch-all-swallow-test.sh` (mirror `detect-banners-test.sh`).

Wire it into `scripts/jobs/gardening/garden-pr.sh` next to the existing detectors (lines 70–82 pattern): declare `DETECT_CATCH_ALL_SWALLOW="$HERE/detect-catch-all-swallow.sh"`, a `GARDEN_CATCH_ALL_SWALLOW_FIXER` env-defaulted to a new `scripts/jobs/handlers/catch-all-swallow-claude.sh` conditional fixer (modeled on `banner-sweep-claude.sh`), and `run_if "$DETECT_CATCH_ALL_SWALLOW" check "$wt" "$base" -- "$GARDEN_CATCH_ALL_SWALLOW_FIXER" "$wt" "$base"`. Cross-reference `skills/saboteur-adversarial-review` / `skills/adversarial-tests` so the juror discipline and the deterministic gate stay consistent. This makes error-class breadth an encoded, reliably-run check rather than an agent judgment the panel keeps missing.
