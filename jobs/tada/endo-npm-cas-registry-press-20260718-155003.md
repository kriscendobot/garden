# Completion report — npm-via-CAS registry-proxy press (2026-07-18 tick)

**The finish line is reached for ESM packages.** `endor run <entry.js>` now resolves, fetches, and **executes** npm dependencies end to end — no npm CLI, no `node_modules`, no lockfile — with packages content-addressed in the CAS, the SQLite registry table as cache/lock file, and Go-like MVS resolution.
