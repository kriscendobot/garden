**Cursor representation**: a host-local one-line file at `GARDEN_STATE/bulletin/cursor` holding the `origin/journal2` commit SHA the bulletin was last reconciled from. It is host-local on purpose (it is each loop's own resume point); multi-host correctness comes from the existing CAS push + idempotent compare, not the cursor. Transitions are computed as `git diff --name-status <cursor>..HEAD -- jobs entries` (job-lifecycle moves plus new progress entries), with a `HEAD~1` fallback on cold start so the first narration is the latest step, never the whole history.

**Cost gate / degradation / restart-resume**: `claude -p` runs only when the deterministic dashboard (minus the volatile `_As of` line and excluding the non-deterministic `## Latest`) differs from what is posted — never on an idle poll, which just short-sleeps. If `claude` is absent or the journalist fails/times out, the loop still writes the deterministic dashboard, preserves the prior `## Latest` block, and advances the cursor, so a journalist failure never wedges the loop or blocks the bulletin. The cursor is advanced durably only after an accepted CAS push (or a no-op reconcile), so a crash mid-cycle re-processes the transition rather than skipping it; on the unchanged/skip path the cursor still advances to head so a transition another host already posted is not re-narrated, which the tests confirm both for the cost-gate restart (no commit, no claude call, stable cursor) and the change path (digest carries only the since-cursor delta).
