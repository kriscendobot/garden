Designed the **cleric worker + factored worker spine + bid auction + dollar-normalized reputation** system and landed it on `main2` as `designs/cleric-worker-bid-auction-reputation.md` (commit `e5ddf9fba0`, with an index row in `designs/README.md` plus a courtesy index row for the sibling `provider-model-catalog.md` reference, which had none).

**What the design specifies:**

- **Cleric (§1):** a codex-backed worker kind — `handlers/cleric-codex.sh` driving `codex exec --dangerously-bypass-approvals-and-sandbox --output-last-message` with `~/.codex` auth, same completion-marker/sentinel contract, session resume via a persisted codex-assigned session id (with a fresh-session-over-preserved-worktree fallback); `garden-cleric@.service` rendered from a shared unit-template source; `clerics: N` in `hosts/<host>` reconciled by the one scaler; a pre-auction claim-eligibility filter so clerics never claim Claude-pinned jobs.
- **Factored spine (§2):** a worker-kind registry in `common.sh` as the single point a new backend touches; `gardener.sh`, claim/complete/reaper, the unit template, the handler prompt text, and the worktree lifecycle all shared; per-kind only the handler, a usage adapter, and a provider tier map/rate card. The handler contract gains `GARDEN_USAGE_OUT` (normalized token usage) so cost capture is backend-agnostic.
- **Bid auction (§3):** decentralized and CAS-safe — bounded bid window, per-bidder bid files (no contention), award by a **deterministic job-seeded Thompson draw** every worker computes identically from journal data (no central auctioneer; explore/exploit built into the award rule), the existing claim push as the sole serialization point (double-award structurally impossible), staged eligibility degrading to today's race for liveness and single/zero-bidder degeneration.
- **Reputation (§4–5):** journal data — per-base events written by `complete-job.sh`, arm projections recomputed by a leader-only reducer, keyed `(kind, provider, model, thoughtfulness) × work_class × target-bar`. Cost is **aggregate dollars**: measured agentic tokens × rate card (riding the accepted tada-token-accounting/token-cost-ledger designs) plus human review inferred from aggregate reviewer-commentary depth at ~$125/hr, with a `source: inferred|measured` schema so the parked review-metering tool's measured signal swaps in without churn. The bid *is* the expected aggregate dollars to merge-worthy. Thoughtfulness is chosen by the bid, so the market learns the cheapest adequate effort per work-class.
- It explicitly supersedes the central **broker** of the prior `gardener-bid-accept-market.md` (per the no-central-auctioneer requirement) while carrying forward everything else from that design and `gardener-reputation-bootstrapping.md`.
