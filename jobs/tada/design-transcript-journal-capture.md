Designed and landed `designs/transcript-journal-capture.md` on `main2` (commit d9c7ad6c7), plus an index row in `designs/README.md`.

**What the design recommends.** Storage is a dedicated `transcripts2` orphan branch (mirroring the journal2 pattern operationally: single-branch clone, reset, CAS push with verification), explicitly rejecting a journal2 subtree (would bloat the branch every fleet service fetches constantly) and `refs/captures` blob storage (no tree, no index, unprunable). The branch lives on a **configurable remote** (`config/transcripts-remote` per-instance journal config, inert until armed, issue-inbox pattern) because I verified the origin `kriskowal/garden` is **public**; a private `garden-transcripts` repo is the recommended target. Transcripts are gzipped (measured 4:1 on a real 1.7MB transcript) and passed through a deterministic token-redaction filter; per-host paths keyed by GARDEN identity prevent cross-host clobber; the per-host clone is blobless + sparse so it never holds the fleet corpus.

**Capture is both triggers, split cheap/expensive:** a no-network spool hook in `gardener-claude.sh`'s completion path, and an hourly every-host `garden-transcript-capture` timer that reconciles settings, drains the spool, sweeps idle sessions (liaison and subagents included), and pushes. **Deletion disable** is the launcher seeding `cleanupPeriodDays: 36500` plus an idempotent jq-merge reconcile every tick, covering existing instances.

**Load-bearing findings baked into the design:** (1) `gardener-claude.sh` already `rm -f`s each job's transcript on completion, so for job sessions that deletion, not `cleanupPeriodDays`, is the primary destroyer; the hook goes immediately before that `rm`, which stays (false-resume hazard). (2) This instance's `~/.claude/settings.json` does **not** actually carry `cleanupPeriodDays` despite the job body saying it was hand-set; the reconcile step fixes this host too. (3) The job base is recoverable from the encoded cwd (`gardener-wt-<base>`), so the index is derivable even for sweep-captured sessions.
