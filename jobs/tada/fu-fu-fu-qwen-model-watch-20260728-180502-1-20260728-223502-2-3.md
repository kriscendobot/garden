**The test was at fault**, not `ollama-serve.sh` — though the fix required adding a seam to the wrapper.

## What was wrong

`scripts/jobs/test/ollama-serve-backoff-test.sh` staged its "Ollama is not installed" case by running the wrapper under a deliberately tiny `PATH` containing no Ollama install dir, on the stated premise that this "makes the precondition deterministic even on a host that has Ollama installed."

That premise is false. The wrapper sources `common.sh`, which **deliberately appends** the image's tool dirs (`/usr/local/bin`, `/usr/bin`, …) to `PATH` — the ps23 inherited-PATH fix, `scripts/jobs/common.sh:309-318`. So `/usr/local/bin/ollama` (present on this host, and on every hermit host — the only place this wrapper runs) was back on `PATH` before the precondition ran. The case found the real binary and exec'd a **real `ollama serve`** on the host under test, then asserted against a log line that never appeared.

It was worse than a stale assertion: the sibling assertion `status -eq 1` passed for the wrong reason (the spawned daemon died on address-in-use because `:11434` was already owned). With the port free, the test would have **hung on a live daemon**. The test also passed on non-hermit hosts, which is why it went unnoticed.

## Fix

`PATH` cannot express the absence, so I added the seam and used it:

- `scripts/jobs/ollama-serve.sh` — `OLLAMA_BIN="${GARDEN_OLLAMA_BIN:-ollama}"`, the same `GARDEN_<NAME>_BIN` pin every other fleet CLI takes (`common.sh` § agent-CLI resolution). Authoritative and fail-closed: an unrunnable pin backs off and exits rather than quietly serving with a different binary. Default behavior is byte-identical to before.
- `scripts/jobs/test/ollama-serve-backoff-test.sh` — the missing case now pins a nonexistent path and **leaves the mock on `PATH`**, so it additionally covers the fail-closed contract (new assertion: an unrunnable pin does not fall back to the ollama on `PATH`). Dropped the four now-dead `basename`/`dirname`/`date`/`sleep` symlinks whose only justification was the false-premise comment.
- `context/operations/local-inference-amd.md` — one clause documenting the pin in the `garden-ollama.service` paragraph.
