# Topic: open-ended-agent-ecologies

> Abstract: Persistent multi-agent environments that seek cumulative, open-ended social and cultural development rather than a fixed task optimum. This topic covers the interaction of ecological constraints, limited agent cognition, shared editable artifacts, and post-hoc interpretation. It is distinct from `llm-agent-frameworks`, which covers the construction/runtime of individual agents, and from `agent-fleet-orchestration`, which covers operationally coordinating a task fleet.
