# Topic: cloud-emulation

> Abstract: Local emulators of public-cloud provider APIs (AWS first) used to run unmodified provider-SDK code in development and CI without a cloud account: what they emulate, how faithfully (API-shape conformance versus behavior parity), how tests assert on side effects, and what they deliberately cannot fake. Seeded 2026-09-28 from fakecloud (open-source LocalStack/Moto alternative). Distinct from `testing` (how to write and run tests generally) and `sandbox-platforms` (isolation for untrusted workloads). Applied analysis for minion.town lives in `journal/projects/minion-town/fakecloud-aws-emulation-fit.md`.
