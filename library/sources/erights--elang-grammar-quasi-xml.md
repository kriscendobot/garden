The **Quasi-Literals and XML** page of E's grammar chapter: an obsolete design
proposal, preserved as abandoned-plan history. It proposed an XML/DOM-tree
direction (parser generator building DOM trees, an XML quasi-parser, Minimal-XML
adoption) that E ultimately rejected in favor of Antlr-based Term / Functor trees.
The enduring idea is that XML expresses trees of symbols like Lisp S-expressions or
Prolog term-trees, so a parse tree is primarily a data structure and only
secondarily a notation.
