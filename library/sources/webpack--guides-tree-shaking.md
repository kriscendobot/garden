Abstract: webpack's tree-shaking guide, the authoritative source for the `"sideEffects"` `package.json` property: `false` marks a package pure and prunable, an array names the side-effectful files to preserve, and the distinction between `sideEffects` (skips whole modules) and `usedExports` tree shaking (prunes exports within a module). It backs the `sideEffects` rows in the package-manifest consumer matrix and the tree-shaking inconsistency.
