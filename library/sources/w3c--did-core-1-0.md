> Abstract: W3C DID Core 1.0 is the Recommendation-level common data model for decentralized identifiers: generic DID/DID-URL syntax, DID documents and their core properties, representations, resolution and dereferencing result shapes, method requirements, and the security/privacy envelope around mutable identifier documents. It is the primary normative source for the `service` / `serviceEndpoint` and `alsoKnownAs` semantics used by the garden's ATProto material.
