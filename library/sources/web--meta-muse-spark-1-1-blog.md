## Abstract

*Introducing Muse Spark 1.1 and the Meta Model API* (Meta Superintelligence Labs, 2026-07-09) is Meta's own launch post for the model Willison harnesses. It frames Muse Spark 1.1 as a **multimodal reasoning model built for agentic tasks** — the successor to Muse Spark 1.0 (April 2026) and the first Spark model exposed through a developer API. Its two agent-relevant faces are captured in this source's two sections: the **capabilities** (agentic planning/orchestration that zero-shot-generalizes to new native tools, MCP servers, and custom skills; computer use across applications; strong coding on large codebases; text/image/video/PDF multimodality; a 1-million-token context window with active compaction; parallel tool calling and structured output) and the **access model** (the new **Meta Model API** in public preview, described as **OpenAI-compatible**; also reachable in "Thinking" mode in the Meta AI app and at meta.ai). Pricing, token cost, and rate-limit numbers are not stated in the post. These are Meta's marketing claims; treat the benchmark-backed detail as living in the evaluation-report source.
