> Abstract: CASK's standalone design-corpus style guide, a single rule: prefer regular English plurals (indexes, matrixes, vertexes, appendixes) over Latin or Greek forms (indices, matrices, vertices, appendices) to be more accessible to non-native English speakers, in both code and prose. The rule is restated in the repository-root `CONTRIBUTING.md`.
