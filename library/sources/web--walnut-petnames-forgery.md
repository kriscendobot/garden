The Walnut capability-patterns page applies petnames to impersonation by partially trusted insiders in a multiparty capability system. Authenticated unforgeable references keep random outsiders out, but an authorized participant can still present a misleading self-name and induce the user to grant secrets or authority. The prescribed UI keeps remote nicknames as proposals and leaves the user's editable petname as the final relationship label.
