> Abstract: OpenSandbox's product entry point presents a language-neutral sandbox protocol implemented by Docker and Kubernetes runtimes, with SDKs, a CLI, and an MCP server exposing lifecycle, command, and file operations. It maps those interfaces onto an extensible component tree and AI workload examples. The MCP surface makes OpenSandbox usable as a coarse remote execution tool, while Endo confinement still depends on which powers a caller delegates into the sandbox and which results it accepts back.
