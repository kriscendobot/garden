"Differences with Inkle's Ink": kni's positioning relative to the language it is an homage to. It names the shared ideas (question/answer option notation, `{curly|brace}` meta-narrative, the `->` divert, thread collection, a JSON parser/runtime split), the mechanical divergences (pure JavaScript, significant whitespace, explicit `>` prompt, fully-qualified `@label`, distinct variable/list/conditional notation), and the capability boundary — what kni lacks that Ink has (typed/enum variables, label-valued variables, modules, user-defined functions) and what kni adds (second-person options, option collection through nested conditionals, go-and-return subroutines, the `<-` terminate operator, and biased-random/Hilbert/hash operators for procedural generation, plus `<hook>` game-specific hooks). Useful for the "fit and gaps" half of this ingest's evaluation.
