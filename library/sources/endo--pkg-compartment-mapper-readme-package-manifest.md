Abstract: The Package Descriptors and Language Extensions portions of `@endo/compartment-mapper`'s README specify the mapper's deliberately limited package-manifest reader and its language hook. It names the seven standard fields the mapper reads, its three export conditions and main fallback, the currently deferred `imports`, wildcard, and files-glob behavior, then defines built-in languages and the per-package `parsers` and TypeScript extension hooks.
