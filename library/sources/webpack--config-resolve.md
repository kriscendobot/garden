Abstract: webpack's `resolve` configuration reference, the authoritative source for how webpack reads `package.json` to resolve module requests: `resolve.mainFields` (legacy entry chain, target-dependent default), `resolve.conditionNames` (dynamically-composed `exports`/`imports` condition set), and `resolve.exportsFields`/`importsFields`/`aliasFields` (which manifest fields drive `exports`, `imports`, and `browser` substitution). It backs the webpack row in the package-manifest consumer matrix.
