> Abstract: The root README of `kriskowal/collections`, a library of JavaScript data structures behind idiomatic, uniform interfaces, published as many separately-versioned `@collections/*` packages. The README is a landing page: it states the design goal (one idiomatic interface across all structures) and catalogs the packages by kind (concrete collections, abstract mixins, operators, helpers). Per-package APIs live in each package's own README and are deferred to a follow-on ingest.
