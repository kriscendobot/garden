Mark S. Miller's *PetName Markup Language* records the Electric Communities origin story, distinguishes global keys and nicknames from private relationship-local petnames, and layers those name kinds to obtain the three desired system properties. Its claim to disprove Zooko overstates the result because Zooko's own essay already presents local petname translation as the workaround.
