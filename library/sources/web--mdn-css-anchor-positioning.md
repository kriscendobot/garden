The MDN reference for CSS anchor positioning: how to tie an absolutely/fixed-positioned element to an **anchor** and place and size it relative to that anchor. Covers the association properties (`anchor-name`, `position-anchor`, `anchor-scope`), the `anchor()` function (positioning to an anchor's edges/center/percentage), the `anchor-size()` function (sizing to an anchor's dimensions), the `position-area` 3×3 region grid, and the overflow toolkit — `position-try-fallbacks` with `flip-block` / `flip-inline` / `flip-start` tactics, `position-area` and custom `@position-try` fallbacks, `position-try-order` proactive selection, `position-visibility`, and anchored container queries — plus a mid-2026 browser-support matrix. The dedicated grounding for the deferred `css-anchor-positioning-and-flip-fallbacks` skill; pairs with the applied walkthrough in `web--goldilocks-select-height`.
