> Abstract: README for `@collections/observable`, the synchronous content-change-observation system underpinning the whole `@collections/*` family and `frb`. Three change kinds (property, range, map), each with before/after variants; child observers stack; observers are pooled and inspectable; plain arrays are promoted to ObservableArray rather than mutating `Array.prototype`. Split into two sections: the change-observation model, and the interface plus handler-dispatch rules.
