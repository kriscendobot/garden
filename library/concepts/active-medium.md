# Active medium

An **active medium** combines representation with execution: its user can read and retrieve material, construct models, run them, observe consequences, revise both content and tools, and express ideas across text, graphics, sound, and simulation. Kay contrasts this with both passive books and teaching machines. The computer's value is not automatic instruction but a responsive surface controlled and programmed by the learner.
