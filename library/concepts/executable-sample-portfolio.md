# executable-sample-portfolio

A sample catalog that does two jobs without conflating them: it is a regression suite covering the framework's languages, lifecycles, topologies, and evidence paths, and it is a reader-facing design library of recognizable, reusable Components. Portfolio value and test value are scored separately, pure torture cases remain but do not lead the catalog, and every sample preserves an independently verifiable specification boundary.
