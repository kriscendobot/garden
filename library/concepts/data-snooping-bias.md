# data-snooping-bias

The inflation of apparent predictive skill caused by trying many models, parameters, or strategies against the same data and reporting the best — the single most-warned-against hazard in the empirical trading/forecasting literature. With enough trials an arbitrarily good in-sample result (Sharpe ratio, R², win rate) can be manufactured with **zero** true skill ("backtest overfitting"; Bailey, Borwein, López de Prado & Zhu 2014, *Notices of the AMS*). The corrections have distinct jobs: the **Diebold–Mariano test** (Diebold & Mariano 1995) compares two given forecasts' losses; **West's predictive-ability inference** (West 1996) adds fitted-model parameter uncertainty; **Giacomini-White conditional predictive ability** (2006) evaluates finite-window forecasting methods and can test whether available information predicts which pre-specified method will do better; **White's Reality Check** (2000) and **Hansen's Superior Predictive Ability (SPA)** test (2005) correct the separate "best of N models beats the benchmark" search event (SPA is preferred because it is robust to poor alternatives); the **Model Confidence Set** (2011) returns the models statistically indistinguishable from the best; and the **Deflated Sharpe Ratio** discounts a reported Sharpe for trials and return non-normality. **Practical rule: account for fitting uncertainty, pre-specify or separately correct every search including conditioning instruments, and apply a search correction before any selected "X beats Y" claim is trusted.**
