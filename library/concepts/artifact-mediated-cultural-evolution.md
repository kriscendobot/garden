# artifact-mediated-cultural-evolution

In TerraLingua, persistent editable artifacts are the external memory through which a population can retain, reuse, and elaborate coordination knowledge across agents and generations. The paper's stronger cumulative-culture criterion is not raw artifact novelty: it requires persistence, accessible prior material, inferred lineage or recombination, and increasing functional structure. This is a reported simulation design and result, not a claim that arbitrary generated artifacts create culture.
