# workers-for-platforms

Cloudflare's product for building a **multi-tenant platform** on top of Workers: a platform operator runs untrusted code written by its own customers (or generated by AI) in secure, isolated, per-customer sandboxes, deploying an unlimited number of applications. Over plain Workers it adds four components (dispatch namespaces, dynamic dispatch Workers, user Workers, optional outbound Workers) and management tooling (custom limits, observability, tags). The generalizable pattern — many tenants' code on a shared serverless runtime, with isolation, a programmable dispatch layer, per-tenant limits, egress control, and fleet tagging — is catalogued under the `multi-tenant-platform` topic.
