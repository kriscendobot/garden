Abstract: The two applications show what a set-valued answer buys you. Applying the MCS to Stock and Watson's (1999) inflation-forecasting models, the informative great-inflation subsample (1970-1983) yields a *sharp* MCS — the data can eliminate most models — while the calmer post-1984 subsample yields a set so large it "lets in almost any model," a direct demonstration that MCS size reports data informativeness rather than analyst indecision. The one model consistently excluded in both periods is the no-change (month) forecast; a second no-change (year) forecast, by contrast, is best post-1984, which reconciles the apparent Stock-Watson-versus-Atkeson-Ohanian disagreement (they used *different* no-change benchmarks). A second application builds MCSs of Taylor-rule regressions under likelihood criteria (quasi-likelihood, AIC, BIC) and again finds the data cannot pin down one specification. The forecast object here is an inflation-*level* RMSE (a mean/level forecast) and, for the Taylor rules, in-sample likelihood fit — neither is a directional-return claim, and the MCS would speak to risk-forecast quality only if run on a variance loss.

The inflation application (§6.1) revisits Stock & Watson (1999): a large set of inflation forecasting models, several with a Phillips-curve interpretation, plus autoregressive and no-change forecasts, extended by the Atkeson-Ohanian (2001) year-over-year no-change forecast. To keep the loss differentials stationary under recursive re-estimation, the authors follow Giacomini-White and estimate on a fixed-width rolling window. Models are scored by RMSE and reported with MCS p-values (Tables 4-5). The headline is the contrast between subsamples: the volatile 1970:M1-1983:M12 great-inflation/disinflation window is informative enough for the MCS to make "relatively sharp choices," retaining roughly seven models driven by real-activity and labor-market variables (consistent with Keynesian aggregate-demand measures); the quieter 1984:M1-1996:M9 window is so uninformative that nearly every candidate survives in the 75% MCS. The persistent exception is the no-change (month) forecast, which never enters the MCS in either period — plausibly because month-to-month inflation is a noisy proxy for core inflation — whereas the no-change (year) forecast enters post-1984 and is in fact best there. That single fact reconciles the literature: Stock-Watson found the Phillips curve beats naive models, Atkeson-Ohanian found a naive model wins, and the two simply deployed different no-change benchmarks (last month's versus last year's inflation). The honest closing note is that "the best inflation forecasting model for the last 35 years of U.S. data remains unanswered because the data provide insufficient information" — a large MCS stated as a finding, not papered over.

The Taylor-rule application (§6.2) uses the regression-model MCS (in-sample likelihood criteria on 25 models: a federal-funds AR(1) plus 24 Taylor-rule regressions over 1979:Q1-2006:Q4). Under all three criteria the MCS settles on rules that satisfy the Taylor principle, include all three real-activity variables and the lagged funds rate — but the AR(1) also survives, so the data again "lack the information to resolve precisely which Taylor rule specification best describes the data." The authors are explicit that this is a *fit* comparison, not a claim about the best monetary-policy rule.

Forecasting boundary for the corpus: the MCS inherits the loss-agnosticism of its DM/West/Reality-Check ancestors, so its economic meaning is fixed entirely by the loss it is run on. Here it is run on inflation-level RMSE and on likelihood fit — mean/level and in-sample-fit objects. Run instead on a variance loss (QLIKE, hMSE) over conditional-volatility forecasts, an MCS is a statement about relative risk-forecast quality; run on a return or direction loss, it is a statement about mean or directional quality. A GARCH-family volatility MCS therefore supports risk sizing and interval calibration, not a claim to forecast the sign of returns — the same distinction the West, White, and GARCH-family sections in this corpus preserve.
