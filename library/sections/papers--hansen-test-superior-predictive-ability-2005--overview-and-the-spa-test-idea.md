Abstract: This is the missing middle link of the corpus's forecast-comparison lineage — pairwise Diebold-Mariano → best-of-N Reality Check → *SPA* → the Model Confidence Set. Hansen's Superior Predictive Ability (SPA) test asks exactly White's Reality Check question — "is a benchmark forecast beaten by *any* of `m` searched alternatives, correcting for the search?" — but answers it with more power and far less sensitivity to which junk models happen to be in the candidate set. The framework is *identical* to White (2000): `m` alternative forecasts are compared to a benchmark (`k = 0`), each object scored by any user-specified loss `L(ξ_t, δ_{k,t−h})`, and predictive ability is defined by expected loss. The relative-performance variable is `d_{k,t} ≡ L_{0,t} − L_{k,t}` (positive means model `k` beats the benchmark), and the null of interest is `H0: µ ≤ 0` where `µ = E(d_t)` — "the benchmark is not inferior to any alternative." Hansen changes only the *test construction*: a **studentized** statistic and a **sample-dependent null distribution**, the two modifications that make an analyst unable to dilute significance by padding the model set with poor forecasts. The test is loss-agnostic, so what a significant SPA result speaks to is fixed entirely by the loss it is run on, not by the procedure.

**SPA vs EPA — why the null is composite.** Diebold-Mariano (1995) and West (1996) test *equal* predictive ability (EPA) between forecasts; that leads to a **simple** null hypothesis. White's framework and Hansen's both test *superior* predictive ability (SPA), where the benchmark is compared to a whole set of alternatives simultaneously — a **composite** inequality null `µ ≤ 0`. The distinction is load-bearing: composite-hypothesis testing has (asymptotic) distributions that depend on nuisance parameters, so the null distribution is not unique. The conventional escape is the **least favorable configuration** (LFC) — the point least favorable to the alternative, here `µ = 0` (every alternative presumed exactly as good as the benchmark). White's Reality Check is an LFC-based test, and Hansen's central finding is that the LFC "leads to some rather unfortunate properties when testing for SPA."

**The Bonferroni intuition for why padding poor models hurts the Reality Check.** Let `p_min` be the smallest of the `m` pairwise p-values (each alternative against the benchmark). A Bonferroni bound test rejects `H0` if `p_min < α/m`. Its power can be driven to **zero** by adding poor, irrelevant alternatives: that raises `m` without moving `p_min`. But sample information will (asymptotically) *identify* those poor alternatives, which lets one use a smaller denominator `α/m_0` with `m_0 ≤ m` the number of genuinely competitive alternatives. Hansen's sample-dependent null distribution is a smooth, valid analogue of this improvement — it does not discard the presumed-poor alternatives entirely, but it reduces their influence on the critical value. This is the whole point: an analyst padding the comparison set with junk models cannot thereby wash out a real result.

**The two recommendations (the SPA recipe).** Relative to the Reality Check, Hansen makes two changes: (1) use the **studentized** test statistic `T^{SPA}_n = max[max_{k} n^{1/2} d̄_k / ω̂_k, 0]`, where `ω̂²_k` estimates `var(n^{1/2} d̄_k)` — dividing each alternative by its own standard error so the maximum is not a comparison of "apples and bananas" in different units of standard deviation; and (2) invoke a null distribution based on `N_m(µ̂^c, Ω̂)` with `µ̂^c` a data-dependent estimator of `µ` that conforms to the null and down-weights the poor/irrelevant alternatives, rather than the LFC's blanket `µ = 0`. (When the benchmark has the best sample performance, `d̄ ≤ 0`, the statistic is normalized to 0 — no evidence against the null.) The details of both modifications are the next two sections.

**Object-agnosticism and the risk-versus-directional distinction.** Because SPA inherits the loss-differential machinery's object-agnosticism, the decision rule `δ_{k,t−h}` can be a point forecast (MSE loss), a density or value-at-risk forecast (Kolmogorov-Smirnov, Kullback-Leibler, or a quantile loss), or a trading rule (`L = −δ_{k,t−1} ξ_t` = negative profit — the benchmark "always long in the market" used by Sullivan, Timmermann & White for technical trading rules). A significant SPA result run on a variance loss (QLIKE, hMSE) is a statement about relative conditional-volatility/risk-forecast quality; run on a return or directional-profit loss it is a statement about mean or directional quality. The procedure does not convert one into the other, and Hansen flags that when the object of interest `ξ_t` is unobserved (as with a latent variance), substituting a **proxy** can make the empirical ranking inconsistent for the intended one — a forward reference to Hansen & Lunde (2005a), the corpus's [Patton (2011)](papers--patton-volatility-forecast-comparison-imperfect-proxies-2011--noisy-proxies-can-reverse-rankings.md) territory.
