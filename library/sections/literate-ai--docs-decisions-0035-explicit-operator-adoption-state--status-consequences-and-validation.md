> Abstract: Status composes existing authoritative readers, adopted trees fail rebuild before qualification, and tests reject forged, stale, skipped, or unauthorized state transitions.

Operators gain a repeatable snapshot and guided create or adopt paths without adding a second planner, project database, daemon, or cache authority. Dynamic adoption metadata travels with the project but remains outside Component and documentation identities.

Validation covers canonical state, transition evidence, doctor and status presentation, plan drift, acknowledgement, conversion blockers, and installed-wheel onboarding and adoption.
