> Abstract: Release class is derived from stable published history, and required collateral is bound through local regeneration, remote preflight, idempotent publication, export verification, and an identity-rich receipt.

An explicit version that matches already-advanced source files does not erase a major or minor transition. Each plan records the stable predecessor and effective class.

A declared terminal document pair must bind local and exported hashes, stable remote IDs, remote versions, the prepared revision, the active account, access observations, and verifier identity. Authentication remains an explicit operator action. Missing or unexpected credentials fail before any remote write, while partial publication stays resumable and cannot be reported as complete.
