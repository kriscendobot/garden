> Abstract: Session start records the user-default provider/model tuple, and a distinct event records a CLI override, making the model selection that seeds frame zero auditable without conflating selection with runtime stack semantics.

The logs describe the initial cursor of the
[never-empty model stack](https://github.com/jordanhubbard/literate-ai/blob/fcc40bc617a2bc2455627db7396a1e016ebfbab6/docs/decisions/0018-never-empty-per-agent-model-stack.md).
ADR 0017 binds how live tests choose that first frame; ADR 0018 separately governs
push, pop, isolation, and current-model behavior after session start.
