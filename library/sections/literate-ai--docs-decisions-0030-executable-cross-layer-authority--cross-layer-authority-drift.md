> Abstract: Skill ownership, deterministic host operations, and logical-versus-native paths were documented once but independently rediscovered by multiple consumers, allowing behavior and authority to drift.

The same defect appeared when an ordinary conformance test crossed a live-model boundary and when optional dependency declarations disappeared between project metadata and generated source inventory. Contracts represented in one layer must remain executable through every projection.
