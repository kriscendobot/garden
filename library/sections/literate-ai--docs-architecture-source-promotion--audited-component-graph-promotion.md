> Abstract: Promotion materializes only seven allowlisted forward-authority kinds through exact content pins, retains inverse-model custody outside Component authority, and turns an evidence-closed reviewed graph into one source-free Component per justified node rather than copying or flattening an accepted source tree.

Every promoted read records kind, target, identity, and byte count in a `GenerationInputAudit`. Source, prompts, model journals, Git metadata, provenance, and `.literate` paths have no admitted authority kind. Translation records, evidence partitions, batch plans, and prompt/response journals remain content-addressed provenance and are revalidated before qualification and authority transition.

The reviewed `ComponentGraphDraft` assigns every observation to exactly one reachable acyclic node and grounds every dependency edge in exact evidence plus a capability supplied by its target. A single node is correct when evidence does not justify a boundary. Multi-node promotion preserves node-local capability requirements and Flavor slots rather than merging the recovered application into one manifest.
