Lines 118-121 carry the key warning: "Warning: if the garbage collector is enabled and you remove all names for a capability you've shared, the other party loses access." The /rm command (lines 113-121) is documented with a surface framing and a depth framing. The surface framing is reference semantics: "This removes the name, not the underlying value. Other names pointing to the same value are unaffected." The depth framing is liveness: when ALL names are removed, the GC may reclaim the capability, and the remote party that received a reference via /share + /adopt-locator loses access. Pet names are GC roots.
