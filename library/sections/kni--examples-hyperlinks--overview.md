> Abstract: One line — `Generated by {https://github.com/kriskowal/kni Kni}.` — showing kni's **hyperlink** brace: a brace whose contents begin with a URL followed by whitespace and link text renders as a link (`Kni` linking to the repo) in HTML output and degrades to plain text in a plain-text renderer. A rendering-only construct not otherwise demonstrated in the examples corpus.

The brace form `{<url> <text>}` is a rendering directive, not a decision-graph construct: the first whitespace-delimited token is the target URL and the remainder is the anchor text. In the `--html` renderer (README command-line-tooling) it becomes an `<a>` element; a command-line transcript falls back to the text alone. This is the reference for emitting a link from a kni script.

This section is a brief pointer ingested for completeness so the examples corpus documents the hyperlink brace; the renderer boundary that decides how it degrades is the HACKNI dialogs-and-renderers section, and the surrounding text conventions live in the MANUAL text-space-and-symbols section.
