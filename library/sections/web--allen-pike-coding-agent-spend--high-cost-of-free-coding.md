## The high cost of free coding

We are in the early stages of rethinking how software engineering works. Some teams are still working toward using many agents at once, and the rest of us are grappling with the side effects of doing so.

Each generation of coding agents is capable of doing more helpful work, and of making yet bigger messes. More factory-like coding patterns require us to develop new tools and expertise to use them well.

Occasionally getting there is messy, expensive, or frustrating. But the prize on the other side is being able to build better and more useful software than we ever could before. Plus, it is a lot of fun to figure out.
