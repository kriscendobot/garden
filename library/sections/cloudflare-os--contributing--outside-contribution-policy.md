Cloudflare OS is not generally seeking external code contributions because review capacity and product coherence, rather than code production, are the limiting resources in an AI-assisted project.

Small fixes that are obviously correct and trivially reviewed may be accepted, but low-value cleanup and changes larger than roughly a dozen lines are likely to be closed. Larger ideas belong in GitHub Discussions. The policy is explicitly temporary and may broaden as the project matures.
