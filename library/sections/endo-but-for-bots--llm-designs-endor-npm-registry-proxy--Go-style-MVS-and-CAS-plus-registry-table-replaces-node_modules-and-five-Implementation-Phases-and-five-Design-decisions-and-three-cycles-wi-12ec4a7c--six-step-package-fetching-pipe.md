```
1. Fetch metadata.    GET registry.npmjs.org/{name}
2. Select version.    From cached metadata, match resolved requirement.
3. Fetch tarball.     GET dist.tarball
4. Verify integrity.  Check dist.integrity (SHA-512) against tarball.
5. Extract to CAS.    Strip 'package/' prefix; CAS-blob each file; build tree entry; CAS-tree the tree.
6. Update registry table.  Insert (name, version, tree_hash, integrity).
```

§Six-named-steps with §the-strip-`package/`-prefix detail — npm tarballs are §gzipped-tar-archives-with-a-`package/`-prefix. §Borrowable-pattern: §when-extracting-a-package-format, §strip-the-known-prefix + §store-each-file-content-addressed + §build-the-tree-entry.

§The-integrity-check-step is §SHA-512-vs-npm's-`dist.integrity` — §sibling to cycle 221 @endo/bundle-source's §endoZipBase64Sha512-integrity-hash. §Two-cycles-with-SHA-512-as-integrity-anchor.
