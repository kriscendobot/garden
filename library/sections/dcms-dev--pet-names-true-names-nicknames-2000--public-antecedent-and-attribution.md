Abstract: Jonathan S. Shapiro's April 11, 2000 dcms-dev post is the earliest public primary source located in this cycle. It explicitly credits “Mark Miller and others” at Electric Communities, then applies their true-name, nickname, and locally scoped petname distinction to a replicated repository. It predates Zooko Wilcox-O'Hearn's October 2001 essay and corrects the common misattribution of the petname idea to later expositors.

Shapiro's repository objects have cryptographic content hashes as true names. Creators assign human-readable nicknames, which may collide. On installation, each repository tries the nickname as a local petname and disambiguates it if already occupied; authorized local users may later rename it. The petname is unique only within that repository, and the post stresses that petnames are purely local.

The post is evidence for the first public appearance found here, not necessarily the invention date. Miller's later PNML page says the Communities.com system was developed earlier for multi-way chat but was never documented for external consumption. Marc Stiegler's 2005 paper independently says petnames were invented at Electric Communities. Bill Frantz's same-day reply says Communities.com was about to release software using the concepts.
