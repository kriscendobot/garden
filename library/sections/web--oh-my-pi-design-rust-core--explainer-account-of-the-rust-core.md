## The account, summarized

- **Framing.** The Rust core is "the performance differentiator": three crates replace three hot paths with native implementations the page claims are 10 to 50 times faster, safer because there are no orphan processes and isolation is copy-on-write. A benchmark table (MacBook Pro M2 Max, 10k-file project) claims speedups from 10x (AST parse, warm shell) to 1200x (snapshot and restore). The page also notes that the Rust code is off the per-turn path, since most agent time is spent waiting on the model stream.
- **`pi-ast`.** A structural editing primitive with four operations, `parseAst`, `findNode` by selector, `replaceNode` preserving comments and formatting, and `serializeAst`, plus `block.rs` (byte-ranged AST chunks), `ops.rs`, and `summary.rs` (short LLM-facing summaries of functions and classes). It claims tree-sitter grammars for 50+ languages, each compiled to a separately loaded WASM blob.
- **`pi-shell`.** A cancelable, resource-bounded process wrapper with `kill_tree` over process groups, streaming stdout and stderr, Unix and Windows (ConPTY) back ends, `ResourceLimits` via `setrlimit`/JobObject, and a SIGTERM, one-second grace, SIGKILL cancellation sequence. It presents the minimizer as "the safety layer for the bash tool" that flags destructive or privileged commands.
- **`pi-iso`.** An `FsPrimitive` chooser (APFS clone, btrfs reflink, overlayfs, ProjFS, generic reflink, full copy) behind a `snapshot`/`restore`/`diff`/`discard` API, with a session lifecycle in which the agent edits a snapshot and the user commits or restores on exit.
- **`pi-natives`.** A loader that picks a per-platform `.node` binary, wraps functions in typed promises, and "falls back to JS if native is missing". NAPI is chosen over WASM for speed. TypeScript types are generated by `napi-derive`.
- **Vendored brush.** Shell parsing is vendored "via git subtree" under `crates/brush-core-vendored/` and `crates/brush-builtins-vendored/`, justified by the minimizer's need to parse commands and a claim that network access during `cargo build` is disallowed.
- **Out of scope.** LLM HTTP clients, the TUI, the web UI, and OpenTelemetry stay in TypeScript.
