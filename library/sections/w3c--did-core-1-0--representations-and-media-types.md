> Abstract: Producers and consumers exchange DID documents as representations of one abstract data model, with registered `application/did+json` and `application/did+ld+json` media types and explicit JSON/JSON-LD production rules.

Representation choice does not change the core property semantics. The JSON representation uses the DID Core JSON form; JSON-LD adds context processing and linked-data semantics. Producers and consumers negotiate and validate representations rather than assuming a single serialization.
