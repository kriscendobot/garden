Cloudflare OS is a company-oriented AI productivity environment that combines an agent chat, per-user generated applications, and a security framework for connecting both to company systems.

Cloudflare OS uses the term operating system in two senses. It is an environment for a company to work productively with AI under controls acceptable to a security team, and it manages AI workloads much as a conventional operating system manages compute workloads. It provides an agent UI preloaded with company context, sandboxed application development for small personal apps called gadgets, and Gatekeepers that apply guardrails to agents and gadgets.

The open-source project is intended to be copied and customized into a company's own environment rather than consumed unchanged as a hosted product.
