> Abstract: The per-element collection operators (Map, Filter, Some and Every). A `map{expression}` block binds a new array once and incrementally projects every add/remove/change of the source through the block expression. A `filter{test}` block maintains an array of just the passing elements, inserting and removing in their proper positions as elements cross the test boundary. `some{}` and `every{}` track incrementally whether any or all elements meet a criterion, and can bind two-way (setting `every` true binds the condition true on each element; setting it false cancels the binding). The block syntax `objects.sum{number}` is shorthand for `objects.map{number}.sum()`.

**Map.** Creates a mapping from a source array to a new array via an expression evaluated on each value. The mapped array is bound once; all changes to the source are incrementally projected into the target.

```javascript
var object = {objects: [{number: 10}, {number: 20}, {number: 30}]};
bind(object, "numbers", {"<-": "objects.map{number}"}); // [10, 20, 30]
object.objects.push({number: 40}); // [10, 20, 30, 40]
```

Any function (`sum`, `average`, ...) can be applied to a mapping; `objects.map{number}.sum()` has the block shorthand `objects.sum{number}`.

**Filter.** A filter block maintains an array containing only the source elements that pass the test. As elements are added, removed, or changed such that they cross from passing to failing or back, the filtered array is incrementally updated in the proper positions, as if regenerated by brute force.

```javascript
var object = {numbers: [1, 2, 3, 4, 5, 6]};
bind(object, "evens", {"<-": "numbers.filter{!(%2)}"}); // [2, 4, 6]
object.numbers.push(7, 8);
object.numbers.shift(); object.numbers.shift(); // [4, 6, 8]
```

**Some and Every.** A `some` block incrementally tracks whether some values meet a criterion; an `every` block whether all do.

```javascript
Bindings.defineBindings({options: [{checked: true}, {checked: false}]}, {
    anyChecked: {"<-": "options.some{checked}"},  // true
    allChecked: {"<-": "options.every{checked}"}  // false
});
```

Both can bind two-way. The caveat (shared with `equals` bindings): when the condition for every element is set true, the condition binds incrementally to true on each element; when set false, the binding is simply canceled (the elements keep their last values).

```javascript
var object = Bindings.defineBindings({options: [{checked: true}, {checked: false}, {checked: false}]}, {
    allChecked: {"<->": "options.every{checked}"},
    noneChecked: {"<->": "!options.some{checked}"}
});
object.allChecked = true;  // each option.checked set true; noneChecked === false
object.allChecked = false; // binding canceled; options keep their values
```
