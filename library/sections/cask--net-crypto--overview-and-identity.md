> Abstract: The current casknet cryptographic design. casknet encrypts all inter-node UDP traffic with ChaCha20-Poly1305 AEAD, keyed by sessions established through a **Noise IK** handshake that performs an authenticated x25519 Diffie-Hellman exchange producing directional transport keys with forward secrecy. The local Unix domain socket (`cask/sock`) stays plaintext and trusted. Every node has a long-lived **ed25519** identity keypair stored at `.cask/id` (private, 64 bytes, mode 0600) and `.cask/id.pub` (public, 32 bytes, mode 0644), generated by `cask init`. For Diffie-Hellman the ed25519 key is converted to x25519 via the standard birational map: the private key is `SHA-512(seed)[:32]` clamped, the public key is the Montgomery u-coordinate `u = (1+y)/(1-y)` computed via `filippo.io/edwards25519`. This design replaces the earlier PSK design where a shared secret keyed BLAKE2b session-key derivation with no DH.

## Overview

casknet encrypts all inter-node UDP traffic using ChaCha20-Poly1305 AEAD, keyed by sessions established via a Noise IK handshake. Each node has a persistent ed25519 identity keypair. Session establishment performs an authenticated Diffie-Hellman key exchange (x25519) that produces directional transport keys with forward secrecy. The local Unix domain socket (`cask/sock`) remains plaintext and trusted.

## Identity

Every cask node has a long-lived ed25519 signing keypair:

- `.cask/id` — ed25519 private key (64 bytes, mode 0600).
- `.cask/id.pub` — ed25519 public key (32 bytes, mode 0644).

Generated by `cask init`. The ed25519 keypair is the node's identity. For Diffie-Hellman operations, ed25519 keys are converted to x25519 using the standard birational map:

- **Private key**: `SHA-512(seed)[:32]`, clamped.
- **Public key**: Montgomery u-coordinate `u = (1+y)/(1-y)` computed via `filippo.io/edwards25519`.
