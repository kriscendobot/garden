Abstract: Toby Murray asks the list to identify recurring object-capability patterns, their first descriptions, and the systems in which they appeared. The seed inventory includes sealer/unsealer pairs and trademarks (Morris's 1973 Gedanken language), revocable forwarders (Redell 1974), coercers, membranes, powerboxes, and related constructions. Replies connect these names to KeyKOS/Gnosis, E, Joule, Caja, Plash, Emily, and Polaris.

The exchange shows why the patterns need provenance. Similar object graphs recur under different names; some systems provide a primitive while others build the same behavior from ordinary objects. The revocable-forwarder discussion also distinguishes a caretaker that merely forwards from a richer facet set that can report or react to brokenness.

For Endo, this thread is the historical index behind several current abstractions: brands and matchers, revocation facets, recursive membranes, powerboxes, and eventual references. The published Miller papers provide canonical explanations for individual patterns; the thread records the practitioners' attempt to assemble them into one lineage.
