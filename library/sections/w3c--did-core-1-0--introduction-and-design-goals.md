> Abstract: DID Core defines decentralized identifiers as URI-shaped identifiers whose associated DID documents carry verification material, service endpoints, and other extensible data, with method-specific systems responsible for creation, update, deactivation, and resolution.

A DID identifies a DID subject and is resolved to a DID document. The Recommendation deliberately separates the common data model and syntax from DID methods: a method supplies the rules and infrastructure that create, resolve, update, and deactivate identifiers. Its design goals include decentralization, control, privacy, security, and interoperability; it does not promise that every DID method supplies every property.
