```
When `endor run entry.js` encounters an `import` of a bare specifier:
1. Look up in entry package's dependencies.
2. Resolve the version using MVS.
3. Check registry table for resolved version.
4. If missing, fetch from npm + store in CAS.
5. Read package.json from CAS tree.
6. Continue the transitive walk.
```
