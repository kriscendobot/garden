- **§the-named-mandatory-Step-4-IS-named-realization-of-cycle-301's-named-compounding-property** (first-explicit-observation):

Cycle 301's COMMON.md named the property:

> the skill ... *indexes on the fly* — adds a shortcut to `keywords.md`, prunes a distraction on a concept page, or drafts a missing concept — so the next reader's search succeeds where yours did not or succeeds faster than yours did. Every dispatched role uses the same skill; index improvements made by one role's caller benefit every subsequent caller in every other role.

Cycle 302's SKILL.md realizes the property as **Step 4 (Index on the fly (mandatory))** with **four named writeback actions**:

1. **4a. Add a shortcut** — when the term was reached via flat-grep, not via keyword index.
2. **4b. Prune a distraction** — when a section was a false positive that wasted reading time.
3. **4c. Draft a missing concept** — when no concept page existed for the term.
4. **4d. Queue a scholar review** — at end of dispatch, batched.

**§the-named-claim-and-realization-pair-across-cycles**: the claim (301) precedes the realization (302) by one cycle. **§the-named-four-named-writeback-actions-IS-the-named-realization-of-the-named-compounding-property**.

§the-named-explicit-mandatory-marker: the heading IS literally "Index on the fly (mandatory)" — the word IS in the section heading. **§the-named-mandatory-IS-named-in-the-heading**.

- **§the-named-four-named-writeback-actions** (first-explicit-observation): each writeback action carries a named **Trigger:** clause and a named **Action:** clause. **§the-named-trigger-action-pair-structure**. **§the-named-when-then-pair-discipline**.

§the-named-trigger-IS-named-the-condition-clause: each named writeback action names the condition that triggers it. **§the-named-conditional-mandatory-discipline** — Step 4 IS overall mandatory; each sub-step IS conditional on its trigger.

§the-named-`@`-style-action-classification: 4a + 4b + 4c + 4d — alphabetical, ordered by frequency-of-application. **§the-named-canonical-sub-step-ordering**.

- **§the-named-five-numbered-steps-IS-the-procedure-shape** (first-explicit-observation): Step 1 (Look up) + Step 2 (Fall back) + Step 3 (Use the answer) + Step 4 (Index on the fly mandatory) + Step 5 (Commit and push). **§the-named-five-numbered-steps**.

- **§the-named-keyword-index-IS-grepped-not-read** (first-explicit-observation):

> **The keyword index is meant to be grepped, not read.** Do not open `keywords.md` in a reader; grep for what you need.

**§the-named-grep-not-read-discipline**: the data structure IS optimized for `grep`, not for sequential reading. **§the-named-keyword-row-shape-IS-grep-anchored**.

§the-named-good-enough-ordering: "Keep alphabetical-ish ordering for readability, but do not spend effort on perfect sort — the file is grepped, not read." **§the-named-effort-economy-IS-named-anti-perfectionism**.

§the-named-the-tool-mediates-access-distinct-from-the-skill-mediates-access: the skill IS the human/agent layer; `grep` IS the tool layer. **§the-named-two-named-mediation-layers** (skill-mediated + tool-mediated).

- **§the-named-Common-confusions-block** (first-explicit-observation):

```markdown
## Common confusions

- "<the misleading term>" sometimes appears in [path/to/distracting-section](...) but that section is about <X>, not this concept. For <X> see [[other-concept-id-or-section]].
```

**§the-named-anti-distraction-discipline**: false positives are NOT deleted from the index; they are NAMED on the concept page where the reader actually converged. **§the-named-additive-pruning-NOT-deletion**.

§the-named-preserve-history-additive-pruning: the index grows; it does not shrink. **§the-named-no-delete-discipline**. **§the-named-disambiguation-IS-on-the-concept-page-not-on-the-keyword-row**.

- **§the-named-status-draft-frontmatter-for-new-concept-drafts** (first-explicit-observation):

**§the-named-draft-vs-current-status-shape**: new concepts start as `draft`; scholar's next cycle audits and may bump to `current`. **§the-named-two-named-status-states-for-concept-pages**.

- **§the-named-scholar-vs-librarian-province-boundary** (first-explicit-observation):

**§the-named-roles-have-named-data-territories**: librarian mutates keywords.md + concepts/; scholar mutates sections/ + sources/ + topics/. **§the-named-explicit-mutate-and-no-mutate-list**.

- **§the-named-end-of-dispatch-batching** (first-explicit-observation):

> At the **end of your dispatch** (not per-lookup), if any writebacks happened, append a brief summary to your role's outgoing missive to scholar.

**§the-named-batch-not-stream-discipline**: writebacks accumulate during the dispatch; the scholar-review-queue IS posted at end. **§the-named-batch-IS-named-amortized-cost**.

§the-named-per-dispatch-summary-IS-named-bullet-list-of-named-writebacks: each writeback IS named with its type (keyword shortcut + new concept draft + distraction pruned) and identifier. **§the-named-three-bullet-shapes-in-the-summary**.

- **§the-named-output-IS-named-focused-brief** (first-explicit-observation):

> A focused brief for the caller:
> - The **concept's one-paragraph summary** (from the concept page body).
> - The **one most relevant section's bold-fact summary** (from the section file).
> - The **source provenance** (source slug + commit + status: current / draft-PR / stale) for any role that needs to verify currency.
> - A note on **what writebacks were applied** (the indexing-on-the-fly shortcut, distraction-prune, or draft-concept that improved the index for the next reader).

**§the-named-output-shape-IS-named-four-named-ingredients**: concept summary + section bold-fact summary + source provenance + writeback note. **§the-named-four-named-output-ingredients**.

- **§the-named-bare-name-vs-path-form-distinction** (first-explicit-observation):

> Code symbols often have a bare-name form (`retention-accumulator`) and a path form (`retention-accumulator.js`); prose terms often have casing variants. The skill's job is to try them all before giving up.

**§the-named-multi-shape-keyword-discipline**: code symbols can appear in multiple forms. **§the-named-exhaustive-variant-search**: "try them all before giving up". **§the-named-named-multi-form-search-discipline**.

- **§the-named-backticks-for-code-symbols-discipline** (first-explicit-observation):

> Distinguish code-symbol keywords from prose keywords with backticks (in both `keywords.md` and concept-page aliases). A maintainer scanning `keywords.md` should be able to tell symbol-vs-prose at a glance.

**§the-named-typographic-disambiguation**: backticks-wrapped IS code-symbol; bare IS prose. **§the-named-glance-readable-distinction**.

§the-named-typographic-discipline-IS-cross-axis: applies to keywords.md AND concept-page aliases. **§the-named-cross-document-typographic-consistency**.

- **§the-named-`[[concept-id]]`-wiki-style-link** (first-explicit-observation):

> A `[[concept-id]]` link inside a concept page is a wiki-style pointer to another concept page in the same directory. A non-matching link is acceptable (it marks something worth writing later, not an error) — same convention as the rest of the library.

**§the-named-wiki-link-as-named-cross-reference-shape**: double-square-bracket IS the convention. **§the-named-non-matching-link-IS-named-TODO-not-error**. **§the-named-graceful-degradation-of-broken-links**.

- **§the-named-concept-pages-may-point-at-sections-that-contradict-the-concept** (first-explicit-observation):

> Concept pages may point at sections that *contradict* the concept under a different framing (the canonical example is `crdt-in-formula-persistence`, which links both where CRDT shape is used and where a bidirectional CRDT was abandoned). This is the point of the concepts axis: collect all the angles on one term.

**§the-named-contradictory-references-IS-named-completeness-property**: a concept page IS a multi-angle collector, not a unilateral definition. **§the-named-concepts-axis-IS-named-multi-perspective-aggregation**.

§the-named-canonical-example-IS-named-explicit: `crdt-in-formula-persistence` IS named as the canonical example of a contradiction-aware concept page. **§the-named-self-documenting-by-example**.

- **§the-named-concept-pages-stay-short** (first-explicit-observation):

> Concept pages stay short. A concept page is a *lookup target*, not a primer. If the body exceeds a screen, consider whether the material wants to be a topic page or a section file instead.

**§the-named-screen-as-named-size-limit**: a screen IS the named-maximum-length. **§the-named-lookup-target-vs-primer-distinction**.

§the-named-three-named-document-sizes-in-the-library: concept page (short lookup, under one screen) + topic page (broader subject) + section file (detailed, can be long). **§the-named-three-storage-shapes-for-library-content**. **§the-named-named-size-as-named-purpose-marker**.

§the-named-overflow-IS-named-redirect: if a concept page overflows, the material wants to be elsewhere. **§the-named-size-driven-relocation-discipline**.
