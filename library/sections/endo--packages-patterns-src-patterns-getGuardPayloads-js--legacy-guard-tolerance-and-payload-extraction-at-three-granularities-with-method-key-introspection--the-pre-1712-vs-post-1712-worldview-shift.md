The opening §file-level comment names the transition the file
mediates:

- **Pre-PR #1712**: Guards were raw records discriminated by a
  `klass:` field — e.g., `{ klass: 'methodGuard', callKind: 'sync',
  argGuards, returnGuard }`. The payload was *the record itself*
  minus the discriminator.

- **Post-PR #1712**: Guards are wrapped envelopes with a `payload:`
  field — e.g., `methodGuard.payload = { callKind, argGuards,
  returnGuard }`. The payload is *the unwrapped envelope content*.

The `get*GuardPayload` adapters normalize both forms to the
post-1712 payload shape. *Helps new consumers cope with old code*
— the consumer never sees the distinction.

The §end-of-life marker is explicit:
