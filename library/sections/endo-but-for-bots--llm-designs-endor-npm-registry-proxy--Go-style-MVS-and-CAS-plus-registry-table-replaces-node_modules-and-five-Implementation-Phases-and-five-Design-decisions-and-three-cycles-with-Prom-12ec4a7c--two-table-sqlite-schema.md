```sql
CREATE TABLE packages (
    name TEXT NOT NULL,
    version TEXT NOT NULL,
    hash TEXT NOT NULL,          -- CAS hash of package tree
    integrity TEXT,              -- npm integrity field (sha512)
    fetched_at INTEGER NOT NULL, -- Unix timestamp
    PRIMARY KEY (name, version)
);

CREATE TABLE package_meta (
    name TEXT PRIMARY KEY,
    versions_json TEXT NOT NULL, -- Cached registry metadata
    fetched_at INTEGER NOT NULL
);
```

§Two-named-tables:
- **`packages`** — `(name, version)` → `hash` (CAS tree hash) + `integrity` (npm sha512) + `fetched_at`.
- **`package_meta`** — `name` → `versions_json` (cached registry metadata) + `fetched_at`.

§Two-different-cache-shapes: §per-version-row in `packages` + §per-package-row in `package_meta`. §The-`package_meta`-table-caches-the-npm-registry's-version-listing-avoiding-repeated-HTTP-requests-during-a-single-resolution-pass.

§Borrowable-pattern: §two-tables-for-two-different-cache-grains (per-version + per-package) — §the-design-uses-a-coarser-cache-for-metadata + §a-finer-cache-for-content.

§Sibling to cycle 221 @endo/bundle-source's §SHA-512-content-addressed-source-map-cache with §two-parallel-directory-structures — both designs §two-layered-caches-with-different-grains. §Two-different-substrates (SQLite tables vs filesystem directories) but §same-discipline.
