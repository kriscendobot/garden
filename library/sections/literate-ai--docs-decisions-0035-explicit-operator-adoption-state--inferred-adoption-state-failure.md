> Abstract: Low-level onboarding commands and filesystem heuristics could not tell operators whether a project was created, adopted, current, or qualified, nor which authority governed its release.

Brownfield conversion proves a safe wrapper and retained-source parity, not that generated specifications have become release authority. Recording adoption stage inside authored project authority would be self-invalidating because the transition would alter the identity of the evidence it cites.
