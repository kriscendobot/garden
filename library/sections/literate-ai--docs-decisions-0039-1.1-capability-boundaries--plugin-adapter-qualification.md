> Abstract: Codex and Claude plugin archives derive from one catalog and qualify through fresh-session discovery plus a real independently accepted generated Component.

Archives bind wheel, source, catalog, and supporting-skill identities while excluding normative forks, hooks, credentials, registration, and permission changes. Cursor and OpenCode release adapters remain unsupported; manifest checks alone cannot qualify a prototype.
